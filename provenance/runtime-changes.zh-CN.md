## 独立重建

重建与导出在项目内独立 Docker/containerd 实例中实测成功，镜像为 `eviweave-workbench:p2-rebuilt`，ID 为 `sha256:a8b3c06e832031d971d4947f8bf74c371282f488dfc9e5e523fd6329caaf19ca`。未覆盖历史镜像标签。基础镜像及全部登记包版本均锁定；实际包查询、TOOLS.md 和 capabilities.json 与历史记录相同。重建导出的离线 doctor 和合成单题/批次/续跑均通过。

重建内容不等于历史原件。两份完整清单有 2,476 项差异：2,447 项内容变化、18 项元数据变化、11 项新增，类别有交集。内容变化包括 2,427 份 Python 字节码、8 份 wheel RECORD、5 份安装日志，以及字体/动态链接器缓存、apt 安装标记和导出身份清单。新增包括锁定清单及安装派生文件；权限差异包括临时目录的 sticky 位、若干系统程序/目录的 setuid/setgid 位及运行时顶层目录模式。历史副本原样保留这些权限，不为与重建结果一致而修改。

两者均可运行不代表逐字节相同；新重建不作为历史环境一致性的替代证据。完整逐项差异、实际版本和执行记录仅在本地审计保存。

## 离线检查与保证边界

`doctor --offline` 明确跳过凭据；默认 doctor 缺 key 仍失败，仅检查变量存在，不声称服务认证通过。实际检查完整清单、固定工具/包摘要、已安装版本、英/中文 OCR、Codex 版本及真实读写挂载。合成工具限定占位端点和无效测试 key，额外禁用网络，通过冻结的 Bubblewrap/运行器/导出器/批次链路执行本地确定性程序，不增加生产 mock harness。

本阶段验证离线链路，没有真实 Codex 推理、付费调用、benchmark 重跑或公开发布。历史模型只记录别名，缺少不可变快照，不能保证未来再次获得逐题相同预测或 333/410。P3–P5 与正式技术报告仍待后续授权。
