# Roadmap / 路线图

All items below are future work, not capabilities delivered by v0.1.0. None authorizes model calls or publication.

以下均为后续工作，不是 v0.1.0 已交付能力，也不构成模型调用或发布授权。

- Complete isolated English/Chinese clean-checkout acceptance and bind final commit, builds and hashes; then perform separately authorized repository/tag/Release publication and anonymous download verification. 完成独立英/中文干净检出验收，绑定最终提交/构建/摘要，再按另行授权创建仓库/标签/Release 并验证匿名下载。
- Verify hosted CI and Python 3.10 execution, evaluate another physical host and broaden platform support only with evidence. 验证托管 CI 和 Python 3.10 实测；验收其他物理宿主，按证据扩展平台支持。
- Design and certify complete online request/cost collection against G1 before enabling it; no promise that frozen Codex 0.145.0 already supports this. 先设计并通过 G1 再启用完整在线请求/费用采集，不宣称冻结 Codex 0.145.0 已支持。
- Develop EviWeave Controlled separately while preserving the V6 baseline and distinct experiment identities; no Controlled code is included in the first release. 独立开发 EviWeave Controlled，保护 V6 基线并区分实验身份；首版不含 Controlled 代码。
- Prepare a formal technical report, longer Chinese/English articles and PDF only after a separate scope decision; additional real experiments require their own authorization, credentials and budget. 另定范围后准备正式技术报告、中英文长文和 PDF；新增真实实验需单独授权、凭据及预算。
